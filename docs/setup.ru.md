# Подключение проекта к ESKA Explorer

Нужна ESKA 0.11.0 или новее с совместимым IDE API 1.9.
При использовании глобальной CLI расширение предложит установку, если она
отсутствует или несовместима.
[Установка и обновления CLI](cli-management.md). Настройка
`eska.explorer.executable` выбирает backend для разработки; при явно заданном
пути проверяется выбранная сборка, а глобальная установка не требуется.
В Remote установка относится к машине проекта, а не локальному компьютеру.

Если в существующем проекте отсутствует `eska.toml`, откройте терминал в его
корне и выполните `eska init`. Выберите подходящие тип проекта, каталог исходников
и workflow по подсказкам CLI. Поддерживаются только Designer XML и типы
`configuration`, `extension`, `processing`, `report`.

Прочитайте предложенные настройки перед сохранением. После настройки снова
выполните **ESKA Explorer: Перезапустить подключение**. Само расширение не
инициализирует проект и не выполняет сборку 1С. Установка CLI требует нажатия кнопки.

## Установка расширения

Сначала установите VSIX через **Extensions → Install from VSIX…**.
[Инструкция установки и сборки](packaging.md).
