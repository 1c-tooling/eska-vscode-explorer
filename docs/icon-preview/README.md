# Образец иконок T80

Откройте `index.html`: три фона и размеры 16/20/24 px. `preview.svg` — статический обзор.
Это предложение стиля; состав и вложенность дерева в образце условны.

SVG созданы для eska из геометрических примитивов, без копирования ресурсов
Конфигуратора или стороннего набора. Это исходные векторные файлы, не растры.
Лицензия репозитория не изменяется. Иконки ещё не подключены к расширению.

Рассмотренный кандидат: [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme),
[MIT](https://github.com/material-extensions/vscode-material-icon-theme/blob/main/LICENSE),
copyright 2025 Material Extensions. При переносе его ресурсов потребуется сохранить
copyright и текст лицензии. В текущем образце его SVG не используются.

Предложение: сохранить знакомые образы и цвета метаданных, убрать градиенты и
мелкие детали; для контрастного режима использовать отдельные монохромные версии.
Регистры различаются цветом и внутренним знаком. В контрастном варианте таблица
и справочник могут отличаться слабо; окончательные значки нужно проверить
в нативном Tree View после согласования направления.

Пока покрыты 22 характерных образа. Полное соответствие всех metadataKind,
групп и ролей модулей, fallback, интеграция и нативная приёмка — оставшаяся T80.
