# Changelog

Версии и записи формируются автоматически из Conventional Commits через Knope.
## 0.0.7 (2026-09-24)

### Features

- Добавлена защита исходников по правилам поддержки 1С
- Добавлено ожидание проверки поддержки перед показом дерева
- Добавлены оранжевые маркеры поддержки к иконкам объектов
- Добавлено отключение проверки поддержки в настройках
- Заменены маркеры поддержки на замки и снятие шифрования
- Добавлено защищённое открытие исходников на поддержке

### Fixes

- Убрано ожидание Git при показе статуса поддержки
- Ограничены группы путей защиты пределами каталога
- Исправлено восстановление защищённых вкладок после перезапуска
- Восстановлена языковая поддержка защищённых модулей

## 0.0.6 (2026-09-22)

### Features

- Добавлен переход из подписки на событие к обработчику

### Fixes

- Кнопки проекта упорядочены как сортировка, фильтр и обновление

## 0.0.5 (2026-09-22)

### Features

- Добавлена алфавитная сортировка отдельно для каждого проекта

### Fixes

- Передан токен Open VSX при автоматической публикации
- Всё дерево метаданных сортируется кнопкой-переключателем

## 0.0.4 (2026-09-21)

### Features

- Добавлены путь к ESKA и проверка обновлений по нажатию

### Fixes

- Различены группы метаданных и типы проектов
- Реквизиты табличных частей окрашены в тёмно-зелёный
- Убрана стрелка после загрузки пустого объекта

## 0.0.3 (2026-09-19)

### Features

- Добавлено дерево файлов рабочей области
- Настройки агентов и редакторов добавлены в дерево проекта
- Добавлены установка и обновление глобальной ESKA

### Fixes

- Убраны лишние уровни дерева конфигураций
- Настройки Git и BSL перенесены в группу настроек проекта
- Скрыты пустые контейнеры участников workspace
- Публикация Cargo проверяется через sparse index
- Отменены незавершённые подключения и проверки CLI при закрытии
- Устранены повторные обновления и удержание удалённых узлов
- Playground создаётся до запуска тестов расширения

## 0.0.2 (2026-09-18)

### Features

- Расширен фильтр на пустые разделы группы «Общие»
- Добавлено прямое открытие модулей и отдельных источников формы
- Добавлено открытие предопределённых элементов в XML
- Добавлены горячие клавиши и переход к открытому файлу
- Добавлена Git-подсветка исходников и групп дерева

### Fixes

- Перенесены статус подключения и команды панели
- Изменена иконка перезапуска подключения
- Название ESKA приведено к верхнему регистру

## 0.0.1 (2026-09-18)

### Features

- Добавлено подключение VS Code к backend eska
- Добавлены дерево метаданных и открытие исходников
- Добавлен выбор языка групп дерева
- Добавлена отмена запросов без разрыва подключения
- Добавлен поиск метаданных с переходом в дерево
- Добавлен фильтр пустых корневых групп для каждого проекта
- Подключены SVG-иконки метаданных для четырёх тем

### Fixes

- Уточнена ошибка backend без поддержки IDE API
- Исправлены отступы дочерних узлов дерева
- Добавлена диагностика остановок backend
- Локализованы типы в результатах поиска
- Общие модули открывают BSL без вложенной группы
- Закреплён порядок кнопок фильтра и обновления
